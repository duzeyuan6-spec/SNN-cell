# Unified PIRC-SNN system experiment: fixed protocol

- Dataset/model: DVS128 Gesture, existing Conv-LIF checkpoint `results/local_seed42/best.pt` (SHA256 `240d3305ec7876999d660af9051479cdcb4e51e8f6f943d4c712e3100aed811d`). No backbone or High retraining.
- Evaluation: all 252 held-out training-subject validation clips in `results/local_seed42/controllers/validation_cache.npz`. Official test labels are not used. This validation split has been examined in earlier work; all new system conclusions remain exploratory.
- Supply: scenario `d64_v50`, capacity 4 tokens per region, initial reserve 2, mean supply 1.6 tokens/bin, four-bin allocation delay, common supply/order seeds 731–740. Each bin's two highest-spiking regions request High, giving exactly 32 original requests/clip. All policies share each seed's original requests and external supply. One High call needs one local token; transfers are adjacent on a 2×2 graph, conserved, at most one token/bin.
- Model output: base path always computes. High executes only when its original request receives a token. Classification uses the same frozen per-bin Low/High logits. Fixed Low never requests High and its RCIR/outage-service values are N/A, not artificially counted as denial.
- Strong traditional baseline: causal resource allocation softmax of 4×current request + 2×local reserve deficit, with fixed one-token donor safety and adjacent sharing.
- Full PIRC: same base allocation plus one-unit four-step demand forecast term. Donor safety target is clip[4×max(EMA_0.95(request)−EMA_0.95(incoming),0) + max(forecast−current_request,0),0,4]. Forecast uses the existing fit-only ridge model with causal current and EMA neural/request features. All supply/transfer choices use current or past observations.
- Remove reserve feedback: set both reserve-deficit allocation term and adaptive donor safety target to zero. Keep the same forecast and sharing.
- Remove activity history: fit a current-only demand predictor on the same 924 fit-subject clips/seeds 701–703 using ridge 0.001 and feature columns [bias,current spike,current request]; use it in place of the full causal history predictor. Keep reserve feedback and sharing.
- Remove sharing: keep full allocation/forecast/safety but disallow inter-region token transfers.
- Preset coefficient 1 on forecast allocation and safety terms; this is a fixed integration choice, not chosen from validation outcomes. No controller grid search or scenario selection.
- Metrics: Accuracy, overall RCIR, outage-bin service, actually executed network MAC/clip, High calls/clip, supply spill fraction, global and adjacent CRSR. Report matched seed means and each seed; do not claim independent uncertainty from the ten supply seeds since all reuse one clip set/checkpoint. Physical replay of one seed verifies cached predictions and actual High skips.
- Outputs: one main table, one matched mechanism-ablation table, raw per-seed CSV, checkpoint/config manifest. Missing causal accumulated-state High input stays labeled absent.

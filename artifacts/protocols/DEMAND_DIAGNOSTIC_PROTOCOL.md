# Locked low-cost demand-information diagnostic

Use existing DVS128 Gesture checkpoint/rate caches; do not retrain the SNN or alter original two-group requests. Run on the six supply traces from `OUTAGE_SWEEP_PROTOCOL.md`, with identical 1.6-token/bin total supply, local reserve capacity 12 and allocation delay 4. The already selected reserve-threshold policy is the reference environment; it supplies local post-service reserve and future unserved original requests. All controllers see only information available by the end of bin t.

Prediction question: for each local group and each horizon H in {16,32}, predict whether at least one original request at t+4 through t+H is unserved by the reference policy. Targets follow the continuous resource stream and may cross gesture-clip boundaries because H exceeds the 16-bin clip length; record this as a limitation. Causal activity history resets at each independent gesture boundary while resource reserves persist across the stream. Exclude only final H bins of each complete resource stream. Use the same reference simulation for both predictors. Model A uses only current local post-service reserve, with a piecewise-linear basis. Model B adds current local neural firing rate, causal EMA at 4 and 16 bins, and current-versus-EMA trend. Both are L2-regularized logistic models with the same fitting code. Measure validation AUROC, AUPRC, log loss and Brier score, emphasizing incremental performance over A. Metrics are calculated per scenario and then equal-weight averaged. Subject-level split: fit 924 training-subject clips and trace seeds 701-703; validation 252 held-out training-subject clips and seeds 711-720. No labels are used to fit predictors.

Deployment question: add the fitted H=16 risk prediction to the frozen reserve-threshold allocation logit as `risk_gain * predicted_risk`, with gains in {0,1,2,4}. Calibrate gain separately for reserve-only and reserve-plus-activity on fit data using the same prespecified objective `0.5*outage_RCIR+0.5*overall_RCIR+0.1*spill_fraction`, then compare on validation against each other and the unchanged reserve-threshold policy. The predictor is frozen; no refitting on validation. A physical High call still requires one local token. Report outage service, overall RCIR, total request service, spill, accuracy from cached same-checkpoint logits, High calls/MAC. Validation accuracy is diagnostic only. Do not run official test or claim test generalization for this diagnostic; prior work reused the official test clips. If added activity has no clear predictive information or does not reduce interruptions against the reserve-only predicted-risk controller, stop rather than add controller complexity.

A potential caveat is that future shortage labels are generated by the reference policy. A changed policy alters future reserves. Evaluate deployed service by full closed-loop simulation, never by merely thresholding the reference predictions. Pair supply seeds and clips. Record full trace-level results; no scenario selection after seeing validation.
